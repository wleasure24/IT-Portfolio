# Home Lab: Windows Virtual Machines and Networking

## Purpose

Build practical IT administration and troubleshooting skills in a personal test environment without changing production systems.

## Equipment

- Dell OptiPlex 5060 Tower
- Intel Core i5-8600 processor
- 16 GB RAM
- 80 GB SSD and 2 TB HDD
- Windows 11 Home host
- 8-port network switch

These are the components documented for this lab; the setup may evolve over time.

## Work completed

1. Created and ran two Windows virtual machines for learning and testing.
2. Adjusted VM processor allocations to two cores during configuration.
3. Created example user identities for two employees, a manager, and an administrator to practice account organization.
4. Explored networking hardware, including an 8-port switch.

## What this demonstrates

- Basic virtual machine setup and resource management
- Organizing test users and roles
- Understanding the relationship between physical hardware, operating systems, and virtual environments
